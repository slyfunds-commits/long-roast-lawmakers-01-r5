Round 5 entry for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert": one satirical sentence roasting lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF. The AI bill passed 412-3 as a Word file — and the three who voted against it were the only ones who could convert it.

`main.py` (pure stdlib) writes the sentence to `/output/entry.txt`, asserts the 1–320 character gate, requires exactly one sentence, and byte-verifies what it wrote.

## Run it

```sh
python3 main.py
```
